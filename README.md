# 投票小程序

微信小程序原生 + 微信云开发（云函数 + 云数据库）实现的轻量投票工具。

## 功能

- 发起投票：问题（必填，≤50字）、2–10 个动态选项、截止时间（必须晚于当前时间）、问题配图（选填 1 张，≤5MB，详情页点击看大图）
- 头像昵称填写能力获取身份，未填写显示「微信用户」
- 列表页：全部 / 进行中 / 已过期三个 Tab，发起时间倒序，下拉刷新 + 上拉加载
- 参与投票：单选，点击选项二次确认，每人每投票仅一票，投后不可改
- 结果展示：票数、百分比、总票数，「我的选择」高亮
- 发起人：可提前结束投票；发起后 10 分钟内可删除（物理删除），过期后禁止删除；无需投票即可查看实时结果
- 分享卡片直达详情页
- 更新公告：仿微信「功能介绍」风格的版本更新列表与详情

## 技术要点

- openid 静默登录（云函数上下文获取，零弹窗）
- 防重复投票：`vote_records` 表 `voteId + openid` 唯一索引 + 云函数前置校验
- 防并发超投：`db.command.inc` 原子自增 + 失败补偿删除
- 过期判定以服务端时间为准，不依赖客户端时钟
- 敏感字段（openid）云函数返回前裁剪，前端零接触
- 头像跨用户可见：云函数 `getTempFileURL` 生成签名临时链接（免费套餐存储权限受限时的解决方案）
- 头像加载失败自动降级为默认头像（云存储文件被删的脏引用兜底）

## 如何发布新版本公告

编辑 `miniprogram/pages/notice/data.js`，在数组**最前面**追加一条：

```js
{
  id: '1.0.2',                    // 唯一标识，用版本号即可
  title: '1.0.2 主要更新',         // 列表标题
  date: '2026-10-20',             // 显示日期
  content: ['第一条更新说明', '第二条更新说明']  // 详情页内容，每行一条
}
```

保存后编译验证，随小程序版本一起上传即可，无需改动云函数或数据库。

## 快速开始

1. 微信开发者工具导入本目录，开通云开发
2. 将环境 ID 填入 `miniprogram/app.js`
3. 按 `docs/02-部署测试清单.md` 完成集合、索引、云函数部署
