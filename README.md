# 投票小程序

微信小程序原生 + 微信云开发（云函数 + 云数据库）实现的轻量投票工具。

## 功能

- 发起投票：问题（必填，≤50字）、2–10 个动态选项、截止时间（必须晚于当前时间）
- 头像昵称填写能力获取身份，未填写显示「微信用户」
- 列表页：全部 / 进行中 / 已过期三个 Tab，发起时间倒序，下拉刷新 + 上拉加载
- 参与投票：单选，点击选项二次确认，每人每投票仅一票，投后不可改
- 结果展示：票数、百分比、总票数，「我的选择」高亮
- 发起人：可提前结束投票；发起后 10 分钟内可删除（物理删除），过期后禁止删除
- 分享卡片直达详情页

## 技术要点

- openid 静默登录（云函数上下文获取，零弹窗）
- 防重复投票：`vote_records` 表 `voteId + openid` 唯一索引 + 云函数前置校验
- 防并发超投：`db.command.inc` 原子自增 + 失败补偿删除
- 过期判定以服务端时间为准，不依赖客户端时钟
- 敏感字段（openid）云函数返回前裁剪，前端零接触

## 目录结构

```
├── project.config.json        # 项目配置
├── miniprogram/               # 小程序前端
│   ├── app.js / app.json / app.wxss / sitemap.json
│   ├── pages/index/           # 列表页
│   ├── pages/create/          # 发起投票页
│   ├── pages/detail/          # 详情页
│   └── utils/util.js          # 公共工具函数
├── cloudfunctions/            # 云函数
│   ├── vote_create/           # 发起投票
│   ├── vote_list/             # 列表分页查询
│   ├── vote_detail/           # 详情查询
│   ├── vote_cast/             # 参与投票
│   ├── vote_delete/           # 发起人删除（10分钟内）
│   └── vote_finish/           # 发起人提前结束
└── docs/
    ├── 01-数据库集合与索引.md  # 数据模型与索引设计
    └── 02-部署测试清单.md      # 部署步骤与测试用例
```

## 快速开始

1. 微信开发者工具导入本目录，开通云开发
2. 将环境 ID 填入 `miniprogram/app.js`
3. 按 `docs/02-部署测试清单.md` 完成集合、索引、云函数部署
