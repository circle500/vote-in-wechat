# 云数据库集合与索引设计

> 所有数据库读写均通过云函数（管理员权限 SDK）完成，前端不直连数据库。
> 集合权限设置为「所有用户不可读写」，是最安全的配置。

## 一、集合：votes（投票主表）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 系统自动生成，即 voteId |
| creatorOpenid | string | 发起人 openid（**不下发前端**，云函数内裁剪） |
| creatorName | string | 发起人昵称，未填写默认「微信用户」 |
| creatorAvatar | string | 发起人头像我云存储 fileID，可为空 |
| question | string | 投票问题，1–50 字 |
| options | array\<object\> | 选项数组，2–10 项，结构见下 |
| options[].id | string | 选项 ID，如 `opt_1` |
| options[].text | string | 选项文案，1–30 字 |
| options[].count | number | 该选项票数，默认 0 |
| totalVotes | number | 总票数，默认 0 |
| isMultiple | bool | 是否多选，当前恒为 false（预留） |
| createdAt | number | 发起时间（服务端毫秒时间戳） |
| expireAt | number | 过期时间（毫秒时间戳） |

**进行中判定**：`expireAt >= 当前服务端时间`；**已过期判定**：`expireAt < 当前服务端时间`。

## 二、集合：vote_records（投票记录表）

| 字段 | 类型 | 说明 |
|---|---|---|
| _id | string | 系统自动生成 |
| voteId | string | 关联 votes._id |
| openid | string | 投票人 openid（**不下发前端**） |
| optionIds | array\<string\> | 已选选项 ID 数组（单选为单元素） |
| createdAt | number | 投票时间（服务端毫秒时间戳） |

## 三、索引配置（云开发控制台 → 数据库 → 集合 → 索引管理）

### vote_records 集合

| 索引名 | 字段 | 类型 | 用途 |
|---|---|---|---|
| vote_openid_unique | voteId（升序）+ openid（升序） | **唯一索引** | 防重复投票的终极兜底，插入重复直接报错 |
| voteId_index | voteId（升序） | 普通索引 | 按投票查询/删除记录 |

### votes 集合

| 索引名 | 字段 | 类型 | 用途 |
|---|---|---|---|
| createdAt_desc | createdAt（降序） | 普通索引 | 列表页按发起时间倒序 |
| expireAt_index | expireAt（升序） | 普通索引 | 进行中/已过期过滤 |

> 数据量增大后，建议为「expireAt + createdAt」建复合索引以优化 Tab 过滤查询。

## 四、权限设置

两个集合均设置为：**所有用户不可读写**（控制台默认模板中的最后一个选项）。
所有读写由云函数以管理员身份完成，openid 等敏感字段在云函数返回前裁剪。

## 五、删除规则（vote_delete 云函数强制）

- 仅发起人可删除（`creatorOpenid === 当前 OPENID`）
- 仅可在**发起后 10 分钟内**撤回（物理删除）
- **已过期投票禁止删除**
- 删除采用事务：votes 主记录 + 该投票全部 vote_records 一并清除

## 六、提前结束规则（vote_finish 云函数）

- 仅发起人可操作，且投票仍在进行中
- 实现方式：将 `expireAt` 更新为当前服务端时间，后续按已过期处理
