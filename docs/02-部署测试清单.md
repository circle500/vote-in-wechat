# 部署测试清单

## 一、部署步骤

### 1. 开通云开发
- [ ] 微信开发者工具导入本项目（选择项目根目录，appid 可先使用测试号）
- [ ] 开发者工具顶部「云开发」→ 开通 → 记录环境 ID
- [ ] 将环境 ID 填入 `miniprogram/app.js` 中 `wx.cloud.init({ env: 'your-env-id' })`

### 2. 创建数据库集合（云开发控制台 → 数据库）
- [ ] 创建集合 `votes`，权限设为「所有用户不可读写」
- [ ] 创建集合 `vote_records`，权限设为「所有用户不可读写」

### 3. 创建索引（集合 → 索引管理）
- [ ] `vote_records`：唯一索引 `voteId`（升序）+ `openid`（升序）——**防重复投票的关键**
- [ ] `vote_records`：普通索引 `voteId`（升序）
- [ ] `votes`：普通索引 `createdAt`（降序）
- [ ] `votes`：普通索引 `expireAt`（升序）

### 4. 上传云函数（共 7 个）
- [ ] 开发者工具左侧 `cloudfunctions` 目录 → 右键每个函数文件夹 →「上传并部署：云端安装依赖」
- [ ] 函数清单：`vote_create` / `vote_list` / `vote_detail` / `vote_cast` / `vote_delete` / `vote_finish` / `stats_overview`（数据看板，管理员专属）
- [ ] 控制台 → 云函数 → 确认 7 个函数均为「运行中」

### 5. 编译运行
- [ ] 重新编译小程序，确认无报错

## 二、功能测试清单

### 发起投票
- [ ] 不填问题提交 → 提示「请输入投票问题」
- [ ] 问题输入 51 字 → 输入框限制在 50 字
- [ ] 选项少于 2 个 → 提示「至少需要2个选项」
- [ ] 选项添加到 10 个后再点添加 → 提示「最多支持10个选项」
- [ ] 两个选项内容相同 → 提示「选项内容不能重复」
- [ ] 过期时间选过去的时间 → 提示「过期时间必须晚于当前时间」
- [ ] 不选头像昵称直接提交 → 列表/详情显示「微信用户」+ 绿色默认头像
- [ ] 正常提交 → 提示「发起成功」，返回列表页且新投票出现在最上方

### 列表页
- [ ] 三个 Tab 切换：全部 / 进行中 / 已过期数据正确
- [ ] 按发起时间倒序排列（最新在最上方）
- [ ] 下拉刷新 → 列表重置并加载最新数据
- [ ] 数据超过 20 条时上拉 → 追加加载，底部显示「加载中...」/「没有更多了」
- [ ] 无数据时显示空状态文案

### 参与投票
- [ ] 进行中投票点击选项 → 弹出二次确认框
- [ ] 确认后 → 显示票数、百分比、总票数，「我的选择」高亮
- [ ] 再次点击选项 → 无任何反应（已投过）
- [ ] 另一台设备/另一微信账号可对同一投票投票
- [ ] 已过期投票 → 仅展示结果，选项不可点击

### 防重复与并发
- [ ] 快速连续点击同一选项多次确认 → 仅计 1 票（唯一索引拦截）
- [ ] 两人同时对同一选项投票 → 票数为 2（原子自增无丢票）
- [ ] 数据库 `vote_records` 中同一 voteId 无重复 openid

### 发起人操作
- [ ] 发起人在 10 分钟内可见「删除投票」，删除后列表不再显示
- [ ] 超过 10 分钟后「删除投票」按钮消失，直接调接口也返回「仅可在发起后10分钟内撤回」
- [ ] 已过期投票发起人无删除按钮，接口返回「投票已过期，禁止删除」
- [ ] 发起人点「提前结束」→ 状态变为已结束，其他人无法再投票
- [ ] 非发起人不显示操作区

### 分享
- [ ] 详情页点「分享给好友」→ 卡片标题为投票问题
- [ ] 好友点击卡片 → 直达对应详情页

### 安全
- [ ] 抓包/调试面板检查 `vote_list`、`vote_detail`、`vote_cast` 返回数据 → 不含任何 openid 字段

## 三、常见问题

| 问题 | 排查 |
|---|---|
| 云函数报「collection not exists」 | 检查集合名是否拼写正确 |
| 投票一直提示「你已投过票」 | 检查唯一索引是否创建成功（未建索引时无法拦截） |
| 头像不显示 | 确认头像已上传云存储且 fileID 正确写入 votes |
| 列表为空但有数据 | 检查集合权限是否为「所有用户不可读写」（云函数走管理员权限不受影响，若前端直连则查不到） |
